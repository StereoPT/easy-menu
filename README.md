## About The Project

[![Product Name Screen Shot][product-screenshot]]()

Easy Menu is an innovative web application designed to help businesses create professional and customisable PDF pricing lists with ease. Whether you're running a restaurant, cafe, or any other type of establishment that requires a pricing list, Easy Menu provides a user-friendly platform to design and generate high-quality pricing lists that can be printed or shared digitally.

## Getting Started

Follow these steps in order to setup the project locally.

### Prerequisites

- [node.js](https://nodejs.org/en/)

### Installation

1. Clone the repo

```sh
git clone https://github.com/StereoPT/easy-menu.git
```

2. Install NPM Packages

```sh
npm install
```

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Usage

To run the script:

```sh
npm run dev
```
